# Fiche de registre prête à reprendre : assistante maternelle qui utilise Arvela

Modèle remis par Arvela, sous-traitant, à toute assistante maternelle qui le demande à contact@arvela.fr. Il suit le modèle de registre simplifié de la CNIL. L’assistante maternelle le recopie, complète les cases entre crochets, le date et le garde (papier ou fichier). Elle le met à jour si ce qu’elle note change.

Pourquoi une fiche : l’article 30 du RGPD demande à chaque responsable de traitement de tenir un registre. La dispense des petites structures ne joue pas ici, car le traitement est régulier et touche des enfants et des données de santé.

| Rubrique | À recopier |
|---|---|
| Responsable du traitement | [Prénom et nom], assistante maternelle agréée, [adresse], [téléphone ou e-mail] |
| Date de création / mise à jour | [date] |
| Nom du traitement | Gestion de l’accueil des enfants et de la paie avec l’application Arvela |
| Finalités | Noter les arrivées et départs, les absences et leur motif ; calculer le salaire et les indemnités à déclarer sur Pajemploi ; suivre mes congés ; préparer la fin d’un contrat ; estimer mon abattement fiscal ; tenir un carnet de liaison avec les parents (seulement avec leur accord écrit) ; leur ouvrir, si je le veux, un lien privé |
| Base légale | Exécution des contrats de travail et obligations de déclaration (paie, congés, impôts). Carnet de liaison et autres données de santé : accord écrit des parents |
| Personnes concernées | Les enfants que j’accueille ; leurs parents, mes employeurs ; moi-même |
| Données | Prénom de l’enfant, nom de la famille, horaires, présences, absences et leur motif, repas, kilomètres, conditions du contrat et montants ; carnet de liaison (repas, sommeil, change, humeur, soins, petits incidents, notes) ; mes congés et absences ; chiffres de mes bulletins |
| Données sensibles | Oui : santé (soins et incidents du carnet, motif « malade », case handicap ou maladie). Je ne note pas de diagnostic |
| Destinataires | Moi ; les parents de chaque enfant, pour leur enfant seulement, par le lien privé si je le crée |
| Sous-traitant | Arvela (éditeur YKM, contact@arvela.fr), selon le contrat des Conditions d’utilisation (article 28). Hébergement par Google à Paris |
| Transferts hors UE | Données stockées à Paris. Google, société américaine, peut y accéder dans les cas décrits dans la politique de confidentialité d’Arvela |
| Durées | Pendant le contrat, puis le temps de mes obligations (déclarations, impôts) ; carnet supprimé si les parents retirent leur accord. Je supprime les données d’un contrat terminé quand je n’en ai plus besoin : [durée choisie] |
| Sécurité | Téléphone verrouillé par un code ; mot de passe du compte Arvela solide et non réutilisé ; lien parent jamais publié, code donné de vive voix ; sauvegarde régulière (Plus › Sauvegarde) gardée en lieu sûr |
| Accord des parents | Réponses écrites gardées : [où] |
| En cas de fuite | Prévenir la CNIL sous 72 heures (téléservice de notification sur cnil.fr) avec l’aide d’Arvela, et les parents si le risque est élevé |
