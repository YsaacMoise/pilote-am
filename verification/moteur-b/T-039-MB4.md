## 2. Décision
- Les trois sources concordent. Art. 105 al. 1 : toute absence de l'enfant sur une période d'accueil prévue est rémunérée. Une seule exception : la maladie justifiée par certificat médical ou bulletin d'hospitalisation, dans les limites de l'al. 3 (déjà gérées par `absence_enfant_malade`). CASF L423-20 ajoute l'absence « du seul fait de l'assistant maternel », qui est une absence de l'AM (déjà gérée par les types `am_*`).
- Aucun texte lu ne prévoit une absence de l'enfant non payée par accord des parties. Le « congé sans solde » de F12812 vise l'AM, pas l'enfant. Il n'y a donc pas deux lectures : le moteur conclut.
- Nouveau type dans B : `qualifier_absence("enfant_sans_solde", type_annee)` renvoie `deductible: False`, règle R-ABS-01, dans les deux types d'année, avec une note qui cite l'art. 105 et renvoie vers `absence_enfant_malade` (maladie justifiée) ou une absence de l'AM (absence de son fait). Aucun montant n'est retenu en silence : le salaire mensualisé est maintenu et la note explique pourquoi.
- Indemnité d'entretien : non due ces jours-là (pas de travail effectif, R-ABS-10, CASF L423-18 al. 2 et CCN 114.1), comme pour toute absence de l'enfant.
- Point non tranché, hors texte, signalé : si les parents et l'AM veulent réellement réduire les périodes d'accueil, cela relève d'une modification du contrat (avenant). Je n'ai lu aucune source qui le dise pour ce cas précis : le moteur ne le traite pas et ne l'affirme pas ; la note se limite aux textes.
